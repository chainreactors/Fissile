# Security

Report suspected vulnerabilities privately through **Report a vulnerability**
on the [Security tab](https://github.com/chainreactors/JevInfer/security) of this
repository. Do not open a public issue.

Include the affected commit or version, the GPU and software environment, and
steps to reproduce.

JevInfer loads native libraries, model checkpoints and projection packs from the
paths in its configuration file. Load them only from trusted sources.
